## Try it in 30 Seconds

Run the self-contained offline demo with zero tokens, API keys, or accounts:

```bash
git clone https://github.com/watt-mind/factory.git
cd factory && bun install
bin/factory demo --dry   # prints the 7-step plan
bin/factory demo         # claim → implement → verify → PR → merge
```

## Core Tenets

<CardGrid stagger>
  <Card title="One Ticket, One Worktree" icon="puzzle">
    Complete filesystem, database, and port isolation. Parallel runs are safe
    because Owned Paths are disjoint.
  </Card>
  <Card title="Verification as a Gate" icon="shield">
    An agent's report is commentary; the test exit code is evidence. Nothing
    merges on self-attestation.
  </Card>
  <Card title="Pluggable Control Plane" icon="setting">
    Works out-of-the-box with **GitHub Issues** and **Linear**. Truth lives in
    git; tasks live in the tracker.
  </Card>
  <Card title="Multi-Harness Architecture" icon="laptop">
    Drives the coding agents you already use: Claude Code, Gemini / Antigravity,
    OpenAI Codex, Cursor, and Pi.
  </Card>
</CardGrid>
